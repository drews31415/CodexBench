| 작업 | 확인 범위 |

| IP11 | B와 C가 동일한 검증된 공개 스냅샷·검사·실행 증거에서 후보를 수집한다. 작업 요청과 필수 지침은 공통 고정 입력 경로로 전달한다. DEFAULT는 시작 시 공통 BM25 순위, 복구 시 평면 진단 순서를 사용한다. |

보조 상한에는 출처와 버전, 구분자, 복구 전략과 핵심 근거, 승인 검사 지침이 포함된다. 두 정책의 복구 핵심 근거가 동일하고 이미 `GENERIC_RETRY`를 사용하므로 최소 크기가 상한을 넘으면 추가 예약 전에 중단한다. 코드 발췌는 공개 스냅샷의 지정·변경 Python 파일에서 함수·클래스 경계로 수집한다. 후보 수집은 Python 경로 및 발췌 각각 최대 64건, 원본 파일당 64 KiB로 제한했다.

모든 점수의 초기값은 기술 명세 §10.3을 따른다. BM25 구현 버전은 `bm25-unicode-word-v1`, 공통 추정기는 `utf8-bytes-div4-v1`이다. 패키지별 선택·제외 근거, 후보 출처, 해시, 처리 시간 및 보조 입력 추정 크기는 `context.jsonl`에 남는다.
